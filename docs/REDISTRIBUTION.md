# Droits du code et des ressources

La publication du dépôt permet sa consultation et son fork selon les conditions GitHub. Aucune licence libre n'est choisie implicitement par l'outillage ; les droits de redistribution générale ne sont pas nouvellement accordés. Voir [la documentation GitHub](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Le dépôt ne contient pas les images, musiques, cartes ou médias historiques de production. Leur diffusion sur le site ne vaut pas autorisation de les copier ou redistribuer. Les exemples de tests sont synthétiques.

Les bibliothèques sont des dépendances déclarées ou des ressources distantes référencées, sans copie de leur code distribué dans ce dépôt. Elles restent soumises à leurs licences respectives. Les crédits des médias de production doivent être gérés séparément ; ils ne justifient aucun import de ces médias dans Git.
