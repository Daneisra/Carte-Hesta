# Synchronisation distante

REMOTE_SYNC_URL et REMOTE_SYNC_TOKEN décrivent une intégration sortante. La configuration PM2 fournie les laisse vides. Ne pas activer cette intégration sans validation du destinataire, des données transmises, de leur confidentialité et de leur rétention.

Les tests utilisent des stubs locaux et bloquent les connexions réelles. Aucun JSON ou média de production ne doit être synchronisé vers Git. Voir [Exploitation](OPS-RUNBOOK.md).
